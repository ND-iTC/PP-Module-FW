## Protection Profile Module for Stateful Traffic Filter Firewalls (FW-Module)

This repository hosts the working versions of the PP-Module for Stateful Traffic 
Filter Firewalls and its Supporting Document. It is used to facilitate collaboration 
and development on future versions of these documents. The latest information can be 
found on the ND iTC home page at https://nd-itc.github.io.

Please use the [Issues feature](https://github.com/ND-iTC/PP-Module-FW/issues/) to 
provide any comments.

## Contributing

If you are interested in contributing to future versions of the FW-Module, please 
consider joining the Network Device iTC by contacting us at 
NetworkDeviceiTC@gmail.com.
